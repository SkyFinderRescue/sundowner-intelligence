# Sundowner Intelligence

Experimental hyperlocal Sundowner prediction and decision-support beta for the Santa Barbara County front country.

## Mission

Sundowner Intelligence is designed for one narrow problem: estimate **where a Sundowner is likely, when it may begin, how strong it may become, how long the threat window may persist, and how confident the system is**. It does not replace official National Weather Service watches, warnings, Red Flag Warnings, spot forecasts, IMET products, agency policy, or field observations.

## Operational zones

The map uses eight separated forecast polygons: Gaviota, Refugio, Goleta, San Marcos Pass, Mission Canyon, Montecito, Toro Canyon, and Carpinteria. Green/yellow/orange/red fill represents low/elevated/high/extreme model probability. Clicking a zone moves the detailed evidence into the sidebar so the default map remains clean.

## Live forecast architecture

- **NOAA HRRR 3-km guidance is the primary short-range source** (`gfs_hrrr` via Open-Meteo); GFS seamless guidance extends/falls back across the 48-hour horizon.
- NOAA NBM supplies an independent high-resolution surface-wind/gust blend when available.
- Western, eastern, and hybrid regimes are scored separately.
- Terrain-relative wind is evaluated at 925, 850, and 700 hPa; 500-hPa flow helps identify wind-reversal/critical-level structure.
- The model includes stability, boundary-layer depth, vertical motion, wind shear, dry-air and marine-layer erosion proxies.
- A Point Conception HRRR reference represents western coastal-jet support.
- Live county DCP/RAWS observations localize current surface response and gust guidance.
- Stale observations are displayed but excluded from forecast weighting.

## Pressure-gradient intelligence

SBA–BFL and SBA–SMX remain the historical anchors, but the live model also uses SBA relative to Santa Ynez (`KIZA`), Vandenberg (`KVBG`), and Lompoc (`KLPC`) when quality-controlled observations are available. The model uses both gradient magnitude and approximate 3-hour tendency, blending current observations into the early forecast window so a rapidly changing pressure field is distinguishable from a static one.

## Upstream precursor intelligence

Cuyama and interior observations are core predictors, not optional display data. The discovery envelope includes Santa Barbara County plus the Santa Ynez Valley, upstream ridges, New Cuyama, North County, and relevant southern Kern stations. The Upstream Precursor Index uses fresh wind direction/speed and dryness to detect favorable interior flow before strong winds are already established in the front country.

## Historical Sundowner intelligence

`data/known-sundowner-events.json` is **Sundowner-first, not fire-first**. Fire association is an outcome field, never the event definition. The primary catalog contains peer-reviewed and strongly documented historical cases with provenance, including both fire-associated and non-fire Sundowners.

`data/swex-2022-events.json` adds the complete set of ten documented SWEX intensive observation periods from April–May 2022, including eastern and western events and the final May 12–13 event whose regime description differs between SWEX sources. The ambiguity is preserved rather than forced into a false single label.

`data/historical-event-reconstructions.json` is generated by joining the documented truth sets to ERA5 reanalysis across all eight forecast zones, Cuyama, and the primary pressure anchors. Reanalysis is used for historical atmospheric context and analog analysis; documented station observations remain preferred for actual event outcomes where available.

Continuous training also includes ordinary non-Sundowner hours, so the probability model learns negatives rather than only famous events.

## Calibration and leakage control

`calibration.json` is the central probability/bias artifact used by the browser. `tools/build-calibration.js` constructs a fixed-lead probability calibration from forecasts that existed before the verifying hour and independent RAWS observations.

The release calibration workflow uses:

- training: March 1–May 31, 2024;
- independent chronological holdout: March 1–May 31, 2025;
- forecast lead: 24 hours;
- source: NOAA HRRR through Open-Meteo Previous Runs;
- targets: terrain-relative observed wind and strong-gust occurrence;
- fire association: **not used to define the target**;
- observed verifying wind: label only, never a predictor of the same historical forecast target;
- regime-specific Platt probability calibration;
- station/zone gust-bias correction where supported by training data.

The event truth set remains separate from continuous hourly labels so documented cases can be used for event-level reconstruction and analog work without leaking verifying observations into forecast predictors.

## Independent validation

`validation/fixed-lead-latest.json` is generated from an independent March–May 2025 fixed-lead test using archived forecast guidance and HADS/RAWS verification. It reports probability metrics, reliability bins, pressure-only and raw-gust baselines, gust MAE/bias, onset timing, peak timing, and cross-zone spatial correctness at 24 and 48 hours. The earlier validation found 24-hour general-event ROC AUC roughly **0.81–0.87**, strong-event ROC AUC roughly **0.90–0.93**, and raw gust MAE **4.5–7.1 mph** at stations where the metric was defined. Performance varies by zone and threshold, so those numbers are evidence of useful discriminatory skill—not proof that the system outperforms every simpler baseline or NWS guidance.

## Quality assurance

GitHub Actions checks JavaScript syntax, model/architecture invariants, the calibration and historical-reconstruction builders, a mocked end-to-end browser flow, public live upstream APIs, fixed-lead historical validation, and the production Pages endpoint. Release verification writes its result to `validation/release-status.json`.

## Safety / scope

This is experimental local decision support. It is not an official warning system. No claim that Sundowner Intelligence outperforms NWS should be made until matched archived NWS forecasts are scored against the same independent observations and cases.
